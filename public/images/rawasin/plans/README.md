# Original Rawasin Mall floor plans

Place the high-resolution floor-plan images exported from the official
`Rawasin Mall - Final.pdf` here, using exactly these base names:

```
basement.jpg   ground.jpg   first.jpg   second.jpg   third.jpg
```

`.jpeg`, `.png` and `.webp` are also accepted. The website checks for these
files at build time and automatically enables the zoomable plan viewer and
full-screen lightbox for each level that has an image. Levels without a file
show a clearly-labelled "original floor plan pending" state — no redrawn or
approximate plans are published.

Do **not** place illustrative renders in this folder: only the original
technical plan drawings from the brochure belong here.
